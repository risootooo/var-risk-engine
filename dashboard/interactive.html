Which VaR model actually deserves your capital?

Nine-plus estimators of Value-at-Risk and Expected Shortfall on one real portfolio — SPY / QQQ / TLT / LQD / GLD, 4,988 trading days from 2007-01-04 to 2026-10-30 — backtested the way Basel model validation does it. This page is not a report: move the weights and the risk numbers recompute live from the embedded return history. The full test tables are the verified Python engine's output.

Verdict: GARCH filtered historical simulation is the only estimator that passes its full backtest (44 exceptions vs 42.4 expected, Kupiec p = 0.80, Basel GREEN). The Gaussian model understates the 99% tail by a third and produces 108 exceptions against 47 expected. Historical simulation sits between — right on average, wrong in clusters.

Kupiec tests the exception rate; Christoffersen tests clustering; Acerbi–Székely Z1/Z2 are signed ES diagnostics reported without p-values (their critical values need simulation of the predictive distribution — attaching one would be false precision). Model card

Data: Yahoo Finance adjusted daily prices, log returns, fixed weights rebalanced daily (documented simplification; no transaction costs in risk figures). Methods: Historical, Gaussian, Student-t, Cornish-Fisher, EWMA (RiskMetrics λ=0.94), Monte Carlo (multivariate normal & t, 200k draws), GARCH / EGARCH / GJR-GARCH filtered historical simulation (arch library), EVT peaks-over-threshold GPD (ξ = 0.23). Validation: Kupiec, Christoffersen, conditional coverage, Acerbi–Székely, Basel traffic light; GARCH backtest refits annually on 750 days. Cross-check: Historical VaR/CVaR independently recomputed with Riskfolio-Lib — max disagreement 0.037 percentage points (a quantile-convention difference at 99%). Deliberate omissions: no √10 scaling (assumes the iid returns the backtests reject), no ES pass/fail verdicts (ES is not elicitable alone), no ML VaR in this version (benchmark first). Code: Python package var_engine with 19 tests, CI, Docker, Streamlit app — see the project zip / repo.

Defence questions: (1) Why does Basel backtest VaR but set FRTB capital on ES? (2) Do Kupiec and the Basel zone agree on the Historical model here — why might they not?
